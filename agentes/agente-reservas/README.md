# Agente Reservas

## Descripcion
Agente de automatizacion para gestion de reservas de mesas y eventos en restaurantes. Integra multiples canales de reserva y sincroniza con el sistema de gestion del restaurante.

## Funcionalidades
- Recepcion de reservas via WhatsApp, web y telefono
- Gestion de disponibilidad en tiempo real
- Confirmaciones y recordatorios automaticos por WhatsApp/SMS
- Integracion con Google Calendar y sistemas POS
- Gestion de listas de espera y cancelaciones

## Tecnologias
- Python 3.10+
- WhatsApp Business API
- Google Calendar API
- Twilio SMS API
- FastAPI

## Instalacion
pip install -r requirements.txt
cp .env.example .env
python main.py
