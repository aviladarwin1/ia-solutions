# Agente Reportes

## Descripcion
Agente de automatizacion para generacion y distribucion de reportes de negocio para restaurantes. Analiza datos de ventas, inventario y clientes para generar informes automaticos.

## Funcionalidades
- Generacion automatica de reportes diarios/semanales/mensuales
- Analisis de ventas y tendencias con IA
- Reportes de inventario y alertas de stock
- Distribucion automatica por email/WhatsApp
- Dashboard de metricas en tiempo real

## Tecnologias
- Python 3.10+
- OpenAI API (analisis de datos)
- Matplotlib/ReportLab (graficos)
- Gmail API (distribucion)
- FastAPI

## Instalacion
pip install -r requirements.txt
cp .env.example .env
python main.py
