# Agente Marketing

## Descripcion
Agente de automatizacion para campanas de marketing digital dirigidas a restaurantes y negocios. Gestiona contenido en redes sociales, envia promociones y analiza el impacto de las campanas.

## Funcionalidades
- Generacion automatica de contenido para redes sociales
- Programacion y publicacion de posts en Instagram/Facebook
- Envio de promociones y ofertas especiales via WhatsApp/Email
- Analisis de metricas de engagement
- Segmentacion de clientes para campanas personalizadas

## Tecnologias
- Python 3.10+
- Meta Business API (Instagram/Facebook)
- OpenAI API (GPT-4 + DALL-E)
- SendGrid API

## Instalacion
pip install -r requirements.txt
cp .env.example .env
python main.py
