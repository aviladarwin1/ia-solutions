# Agente WhatsApp Fudo

## Descripción
Agente de automatización para gestión de pedidos y atención al cliente vía WhatsApp integrado con el sistema Fudo POS para restaurantes.

## Funcionalidades
- Recepción y gestión de pedidos por WhatsApp
- Integración con Fudo POS para registro automático de órdenes
- Respuestas automáticas a consultas frecuentes
- Notificaciones de estado del pedido al cliente
- Gestión del menú y disponibilidad de productos

## Tecnologías
- Python 3.10+
- WhatsApp Business API
- Fudo API REST
- FastAPI

## Instalación
```bash
pip install -r requirements.txt
cp .env.example .env
python main.py
```
